# Lab 2: GradeCalculator

## เกณฑ์การตัดเกรด (Grading Criteria)

| ช่วงคะแนน | เกรดที่ได้ |
| :---: | :---: |
| 80 – 100 | **A** |
| 75 – 79 | **B+** |
| 70 – 74 | **B** |
| 65 – 69 | **C+** |
| 60 – 64 | **C** |
| 55 – 59 | **D+** |
| 50 – 54 | **D** |
| 0 – 49 | **F** |
| น้อยกว่า 0 หรือ มากกว่า 100 | แจ้งเตือนข้อผิดพลาด (`IllegalArgumentException`) |
